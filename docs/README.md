# Docs

Setup and troubleshooting guides for running `m8c` on handhelds.

## Available now

- [`install.md`](install.md) - where to put each file for muOS and Knulli, controls, and
  common fixes (permissions, audio).
- [`sdl3-westonpack-notes.md`](sdl3-westonpack-notes.md) - WIP investigation into running
  the newer SDL3 `m8c` releases on-device.

For the original Docker build instructions this project started from, see
[jamesMcMeex/m8c-rg35xx-knulli](https://github.com/jamesMcMeex/m8c-rg35xx-knulli).
